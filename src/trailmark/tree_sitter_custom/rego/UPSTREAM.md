Pinned revision: `da2a1f63cd877efb05d56de61fe516e90012b9a7`

The upstream MIT license is included in `LICENSE`. Trailmark allows a `ref` in
bracket indices, retaining both bare variables and compound references such as
`types[input.request.object.spec.type]`. This corrects a grammar rejection that
otherwise makes the complete policy file enter error recovery. The grammar does
not evaluate references or infer their runtime values.

Generated C parsers are build artifacts generated by the pinned tree-sitter CLI.
